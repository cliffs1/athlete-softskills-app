# Athlete Soft Skills App
This app is used to help athletes that participate in team sports to train their soft skills. With this app athletes can have a structured training regimen, which is built with researched methods in order for the athlete to achieve better results.
## How it's made
**Programming language: Dart**\
**Framework: Flutter**\
**Database: Supabase**
## Usage instructions
1. Download the repository files
2. Using Android Studio run the program either on an emulator or on a browser
3. Test the program by firstly doing the main test that evaluates your soft skills and then testing all the functionalities that the program offers \
It is also possible to generate an .apk file through Android Studio and download that file to android devices.
